# Home Assistant is een read-only configuratiebron

ONE.OS importeert actuele waarden en metadata uit Home Assistant, maar schrijft namen, ontologyclassificaties, eenheden, decimalen, cloudselectie of andere commissioning-overrides nooit automatisch terug. Home Assistant blijft de technische bron; ONE.OS bezit zijn commerciële normalisatie en presentatie, behoudt bewuste overrides bij brondrift en biedt per veld een herstel naar de actuele Home Assistant-standaard.
