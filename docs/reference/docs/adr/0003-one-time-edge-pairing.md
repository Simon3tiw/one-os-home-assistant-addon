# Pairing via Installation ID, proof-of-possession en eenmalige code

Een nieuwe Home Assistant add-on genereert lokaal een stabiele Installation ID, een keypair waarvan de private key de add-on nooit verlaat en een cryptografisch willekeurige pairingcode van minimaal twaalf goed onderscheidbare tekens met een korte, expliciete TTL. De edge valideert de HTTPS-server via de normale PKI-keten; private PKI of certificaatpinning vereist een afzonderlijk door de installateur bevestigde trustbootstrap. De edge registreert alleen de public key en bewijst bezit van de private key door een servernonce te ondertekenen. De installateur voert Installation ID en pairingcode in ONE.OS Operations in om de installatie aan een Tenant en Site te koppelen; de server bewaart de code alleen gehasht, rate-limit pogingen per bron en Installation ID en voert de claim atomisch exact eenmaal uit. Pas na geldige claim én proof-of-possession wordt een intrekbare devicecredential uitgegeven. Herpairing vereist een expliciete lokale reset en een nieuwe code; claim, uitgifte, intrekking en herpairing zijn auditbare statustransities.
