# Source-verified Home Assistant WebSocket-contract voor discovery en adminverificatie

Fase 2A gebruikt voor volledige lokale discovery en administratorverificatie een expliciet begrensd, read-only Home Assistant Core WebSocket-compatibiliteitscontract: `config/floor_registry/list`, `config/area_registry/list`, `config/device_registry/list`, `config/entity_registry/list` en `config/auth/list`, naast de gedocumenteerde state/config-readinterfaces en eventsubscriptions. Deze opdrachten zijn in de officiële Home Assistant Core-bron voor release `2025.1.0` geverifieerd; de add-on declareert daarom minimaal Home Assistant `2025.1.0`, legt versioned request/responsefixtures vast en test de oudste en actuele ondersteunde release. Dit contract wordt niet als onbeperkt stabiele publieke API voorgesteld: onbekende responsevelden worden tolerant genegeerd, ontbrekende verplichte velden of opdrachten zetten de connector in de niet-commissionable status `incompatible_home_assistant`, en geen enkele generieke WebSocket-send- of mutatie-interface wordt geëxposeerd. Een toekomstige officieel gedocumenteerde registry-API mag deze adapter vervangen zonder het ONE.OS-domeincontract te wijzigen.
