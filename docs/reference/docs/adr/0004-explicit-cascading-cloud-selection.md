# Expliciete cascaderende cloudselectie

De add-on ontdekt lokaal alle bronobjecten maar publiceert standaard niets. Ieder Point bewaart afzonderlijk `selectionIntent = include | exclude | unset` en `reviewStatus = unreviewed | reviewed`; effectieve publicatie vereist include, reviewed en een actieve bron. Een actie op Structure, Space of Asset is één geaudite bulkmutatie over de bestaande descendant Points; include van onbeoordeelde Points vereist expliciete review-en-selectiebevestiging. Parentstatus is alleen berekende tri-state en geen blijvende inheritance-policy, zodat nieuwe kinderen `unset/unreviewed` starten. Move/split/merge behouden intentie en review; Missing bewaart beide zonder waarden te publiceren; Archived is effectief uit; replacement zet review terug op unreviewed. Alleen voor effectief geselecteerde Points vertrekt minimale ancestorcontext. Cloudbediening is volledig afzonderlijk en standaard uit.
