# Add-on gebruikt een afzonderlijke repository met de ONE.OS-stack

De Home Assistant OS add-on wordt gebouwd in de afzonderlijke private repository `Simon3tiw/one-os-home-assistant-addon` met een FastAPI/Python-backend, React/TypeScript/Vite-commissioning-UI, SQLAlchemy/Alembic en SQLite onder persistente add-ondata. Zij gebruikt dezelfde domeintaal, design tokens en kwaliteitsnormen als ONE.OS, maar heeft geen runtime- of buildafhankelijkheid op de centrale monorepository. Gedeelde cloud-/domeincontracten worden als expliciet versieerbare JSON Schema/OpenAPI-artefacten vastgelegd en later gecontroleerd tussen repositories gesynchroniseerd. De container ondersteunt minimaal amd64 en aarch64, wordt uitsluitend via Supervisor Ingress bediend en houdt Home Assistant-, MQTT- en cloudcommunicatie server-side.
