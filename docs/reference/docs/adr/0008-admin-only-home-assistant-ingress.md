# Commissioning uitsluitend voor Home Assistant-administrators via Ingress

De volledige commissioning-UI en alle gevoelige read- en mutatie-API’s zijn alleen via Supervisor Ingress voor een actuele actieve HA-administrator beschikbaar. `panel_admin` is defense-in-depth: de backend accepteert alleen de gedocumenteerde Ingress-proxy, vereist `X-Remote-User-Id`, verifieert die via het gepinde read-only authcontract als lid van `system-admin` en faalt gesloten. Alleen payloadvrije health mag zijn uitgezonderd. Mutaties vereisen JSON, exact same-origin `Origin`, `Sec-Fetch-Site: same-origin` en een kortlevend per gebruiker uitgegeven CSRF-token in een custom header; WebSocket/SSE valideert proxy, Origin en adminstatus opnieuw. Directe backendtoegang, wildcard-CORS, cross-origin credentials en een aparte LAN-beheerpoort zijn verboden. Secrets worden nooit teruggegeven en mutaties worden lokaal geaudit.
