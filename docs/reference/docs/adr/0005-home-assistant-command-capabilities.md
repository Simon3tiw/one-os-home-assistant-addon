# Home Assistant-bronbewijs begrenst de CommandCapability

Home Assistant biedt geen universeel CommandCapability-object. De add-on bewaart per Point relevant read-only bronbewijs en projecteert dit met een versieerbare adapter deterministisch naar een nooit ruimere, niet-handmatig-bewerkbare ONE.OS CommandCapability. Onbekende of ambigue brondata levert geen bediening op. `cloudControlEnabled` staat voor ieder nieuw of vervangen Point standaard uit en wordt nooit door cloudselectie geactiveerd; normale bediening vereist bewuste opt-in en hoog-risicofuncties blijven geblokkeerd totdat een strengere policy bestaat. Adapterversie en bronbewijshash worden bewaard; drift in acties, type, grenzen, opties of risico zet control atomisch uit en `capabilityReviewRequired` aan, zonder de afzonderlijke meetdataselectie te wijzigen.
